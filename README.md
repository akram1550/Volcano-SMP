# VOLCANO SMP Discord Bot

## Pterodactyl Setup
1. Upload and extract this project.
2. Set the environment variable `DISCORD_TOKEN` in Startup/Variables.
3. Use startup command: `python3 main.py`
4. Install dependencies with: `pip install -r requirements.txt`

## Discord Developer Portal
Enable these privileged gateway intents:
- Server Members Intent
- Message Content Intent

## First-time setup
1. Run `/ticket category` and select the category for tickets.
2. Run `/ticket supportrole` and select your staff role.
3. Run `/ticket panel` in your ticket-panel channel.
4. Run `/log_set` to choose a log channel.

Never share your bot token.
